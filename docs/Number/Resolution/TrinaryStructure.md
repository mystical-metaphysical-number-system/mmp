# The Trinary Structure

Three distinct **ontological levels**, each with its own behavior under $\odot$:

| Level | Objects | Nature |
|-------|---------|--------|
| 0 | null $\{\}$ | unresolved, the pole itself |
| 1 | $\{\}_+$, $\{\}_-$ | oriented voids, fixed points |
| 2 | $\{\{\}\} = \pm 1$ | resolved unity, signed |

$\{\}_-$ as "negative zero" and $\{\}_+$ as "positive zero" maps onto IEEE 754 floating-point distinction between $+0$ and $-0$ — which most programmers treat as a curiosity but MMP would say is **physically necessary**.
